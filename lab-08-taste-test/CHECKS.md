# BrewCrew — shared acceptance checks

Both versions were built to the same product spec and both pass all five checks below. (After
Lab 7, you know better than to take that sentence on faith — verifying it is Part 1 of the lab.)

1. **Add works** — adding "Sam, flat white, regular" shows Sam's entry in the run.
2. **Money is exact** — a flat white ($4.50), a large long black ($4.50), and a chai ($4.00)
   total exactly $13.00.
3. **Large costs 50c** — the same drink large is exactly $0.50 more than regular.
4. **No anonymous drinks** — adding with an empty name shows a message and adds nothing.
5. **The café gets the truth** — the copied summary lists every order line and the exact total.

Note what these checks *don't* cover: which version is faster to use, which one people trust,
which one a stranger enjoys. That's the lab.
