# How the two BrewCrews were made (no spoilers — the difference is the visible point)

Per the series' dogfood rule, both versions were vibe-coded from **one product spec** (an office
coffee-run order page: name + drink + size → running list, exact totals, copyable summary,
polite empty-name handling — see the five checks in [`CHECKS.md`](CHECKS.md)) plus **two
opposite taste briefs**:

- **`brewcrew-a/` — "The console."** Brief: *this is a tool for the person who does the run
  every day. Zero ceremony, everything on one screen, keyboard-first, fast over friendly.
  Terseness is a feature. If it looks like a spreadsheet, good.*
- **`brewcrew-b/` — "The invitation."** Brief: *this is for whoever got volunteered this
  morning. One decision at a time, big targets, warm words, nobody feels stupid. Reassurance is
  a feature. If it takes an extra tap, fine.*

Same spec. Same checks. Same five drinks at the same prices. Every difference you can feel is a
taste decision one brief made and the other refused — which is the entire lab.
